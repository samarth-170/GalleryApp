# Image Gallery App
A responsive **Image Gallery App** built using **React**, **Tailwind CSS**, and **Axios**. The application fetches images dynamically from the **Picsum Photos API** and displays them in a modern gallery layout. Users can navigate through multiple pages of images using simple pagination controls.
This project was created to practice React concepts such as Hooks, API integration, asynchronous data fetching, state management, and dynamic rendering.
---

## Features
- Fetches images from the Picsum Photos API
- Displays images in a responsive gallery layout
- Shows the author's name for each image
- Previous and Next page navigation
- Dynamic data loading using Axios
- Real-time UI updates with React Hooks
- Clean and responsive user interface

## How to Use
1. Open the application.
2. Browse the images displayed on the current page.
3. Click **Next** to load the next set of images.
4. Click **Previous** to return to the previous page.
5. View the author's name below each image.

## Installation & Setup
1. Clone the repository:

```bash
git clone https://github.com/your-username/image-gallery-app.git
```

2. Navigate to the project folder:

```bash
cd image-gallery-app
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open the local development URL displayed in your terminal.
